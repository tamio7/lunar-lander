# 🚀 アポロ月面着陸ゲーム

アポロ宇宙船の着陸船を操縦して、月面の着陸パッドに安全に降ろすゲームです。
パソコンでもスマートフォンでも、ブラウザだけで遊べます。

## ▶ 遊ぶ

https://tamio7.github.io/lunar-lander/lunar-lander.html

## 🎯 目標

緑色の着陸パッドに、次の条件で着陸できれば成功です。

- 垂直速度（落ちる速さ）：2.0 m/s 以下
- 横速度：1.0 m/s 以下

燃料には限りがあります。燃料が切れると、あとは重力にまかせるしかありません。

## 🎮 操作方法

### パソコン
| キー | 動作 |
|---|---|
| ＋ / ↑ | 噴射を強くする |
| － / ↓ | 噴射を弱くする |
| ← → | 横方向に噴射 |
| Space / Enter | もう一度遊ぶ |

### スマートフォン
画面のボタンで操作します。終わったら画面をタップすると、もう一度遊べます。

## 💡 コツ

- 高いところでは噴射を控えめにして、燃料を節約しましょう
- 地面に近づいたら噴射を強めて、ゆっくり降りましょう
- 横速度は早めに 0 に近づけておくと安心です
